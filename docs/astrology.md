# Astrology

Vittix now includes astrology capabilities beyond basic Panchang.

Supported Astrology features:

- House calculation with Ascendant (Lagna)
- Planetary dignity and strength
- Classical yogas detection
- Vimshottari Dasha support
- Divisional charts (Vargas)
- Aspect evaluation and chart analysis

Consult the API reference for the available astrology methods on the `Panchang` facade.
