# Accuracy

Vittix uses a pure PHP astronomy engine built for accuracy and reliability.

Key accuracy features:

- Planetary positions using truncated VSOP87 series
- Nutation and true obliquity calculations
- Sidereal conversions with configurable ayanamsa
- Ascendant longitude computed using Meeus formulas
- Mean Rahu/Ketu lunar nodes calculated from nutation terms

This package is designed to avoid external binaries, network dependencies, or native extensions.
