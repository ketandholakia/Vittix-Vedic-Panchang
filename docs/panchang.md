# Panchang

Vittix Vedic Panchang provides daily and moment-based Panchang details including:

- Tithi
- Nakshatra
- Yoga
- Karana
- Vara
- Sunrise and Sunset
- Muhurta helpers
- Festival detection
- Lunar month and Janmarashi calculations

The engine supports sunrise-based day boundaries and can return Panchang state for any instant.
