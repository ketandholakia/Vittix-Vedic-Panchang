# Kundli

This release introduces Kundli (birth chart) support to the Vittix engine.

Features include:

- Ascendant (Lagna) calculation
- Whole-sign house placement
- Planet positions in Rashis
- Rashi and degree mapping
- Rahu/Ketu mean node support
- Divisional chart support via `varga()`

Use `Panchang::kundali()` to generate a full birth chart from a moment and location.
