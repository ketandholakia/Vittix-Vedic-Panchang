# Installation

## Requirements
- PHP 8.2 or newer
- Composer

## Install via Composer

```bash
composer require vittix/panchang
```

## Development Setup

```bash
git clone https://github.com/ketandholakia/Vittix-Vedic-Panchang.git
cd Vittix-Vedic-Panchang
composer install
```

## Supported Platforms
This package is designed for PHP applications and can be used in plain PHP projects as well as Laravel applications.
