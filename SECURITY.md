# Security Policy

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly via GitHub Issues or by email to `dev@vittix.local`.

Do not use issue trackers for exploit proof-of-concept details; instead share them privately and avoid publishing them publicly until a fix is available.

## Supported Versions
This repository accepts security reports for the latest stable release and the current development branch.

## Response Process
1. Report the issue privately if possible.
2. The maintainers will acknowledge receipt within 48 hours.
3. The issue will be investigated and patched in a timely manner.

## Disclosure
Please allow the maintainers reasonable time to resolve the issue before disclosing it publicly.
